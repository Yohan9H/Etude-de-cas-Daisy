## Agent skills

### Issue tracker

Issues et specs en fichiers markdown locaux sous `.scratch/<feature>/`. Voir `docs/agents/issue-tracker.md`.

### Triage labels

Les cinq rôles canoniques par défaut (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), notés sur une ligne `Status:`. Voir `docs/agents/triage-labels.md`.

### Domain docs

Single-context : `GLOSSARY.md` et `docs/adr/` à la racine. Voir `docs/agents/domain.md`.

## Langue

Rédige en français tout ce qui est produit dans ce repo (GLOSSARY.md, ADR, specs, tickets, rapports).
Garde en l'état les noms de fichiers et les marqueurs lus par les skills (`Status:`, `Blocked by:`, `Type:`, `## Comments`, `## Answer`, libellés de triage).
