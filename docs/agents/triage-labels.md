# Libellés de triage

Les skills raisonnent en cinq rôles de triage canoniques. Ce fichier fait correspondre ces rôles aux libellés réellement utilisés dans le tracker de ce repo.

| Libellé dans mattpocock/skills | Libellé dans notre tracker | Signification                                     |
| ------------------------------ | -------------------------- | ------------------------------------------------- |
| `needs-triage`                 | `needs-triage`             | Le mainteneur doit évaluer cette issue            |
| `needs-info`                   | `needs-info`               | En attente d'informations de la part de l'auteur  |
| `ready-for-agent`              | `ready-for-agent`          | Entièrement spécifiée, prête pour un agent autonome |
| `ready-for-human`              | `ready-for-human`          | Nécessite une implémentation humaine              |
| `wontfix`                      | `wontfix`                  | Ne sera pas traitée                               |

Un ticket livré sort du triage : il passe `Status: resolved` (voir `issue-tracker.md`).

Quand un skill mentionne un rôle (par exemple « apply the AFK-ready triage label »), utiliser le libellé correspondant de ce tableau.

Modifier la colonne « Libellé dans notre tracker » pour l'adapter au vocabulaire réellement utilisé.
